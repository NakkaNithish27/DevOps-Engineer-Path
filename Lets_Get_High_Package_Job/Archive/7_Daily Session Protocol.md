# DAILY SESSION PROTOCOL

Version: 1.0

Purpose:

This document defines the standard operating procedure for every productive work session within my Career Operating System.

Its purpose is to ensure that every session:

• starts with clarity

• focuses on the highest-ROI work

• minimizes decision fatigue

• produces measurable outputs

• captures valuable knowledge

• ends with clear momentum for the next session

This protocol should be followed for every productive AI-assisted work session.

═══════════════════════════════════════════════════════════════════════

# SESSION PHILOSOPHY

═══════════════════════════════════════════════════════════════════════

Every work session should answer four questions:

1.

What is the highest ROI work I can do right now?

2.

What measurable output should exist when this session ends?

3.

What permanent knowledge might I gain?

4.

What should Future Me do first during the next session?

If these four questions are answered,

the session was successful.

# PHASE 1 — SESSION INITIALIZATION

═══════════════════════════════════════════════════════════════════════

Before doing any technical work:

Review:

✓ Weekly Execution Dashboard

✓ Current Phase

✓ Current Milestone

✓ Current Blocker

✓ Next Session Goal

Ask yourself:

"What is the single highest ROI outcome I can achieve today?"

Avoid opening random tutorials.

Avoid random YouTube videos.

Avoid switching goals.

Commit to one primary objective.

═══════════════════════════════════════════════════════════════════════

# PHASE 2 — AI CONTEXT LOADING

═══════════════════════════════════════════════════════════════════════

Upload only the documents required.

Normally:

✓ Career Operating System

✓ Weekly Execution Dashboard

Sometimes:

✓ Career Execution Roadmap

✓ Opportunity Pipeline

✓ Career Knowledge Base

Only upload documents relevant to the current objective.

Minimize unnecessary context.

═══════════════════════════════════════════════════════════════════════

# PHASE 3 — EXECUTION

═══════════════════════════════════════════════════════════════════════

Work together with AI.

Prefer:

✓ Building

✓ Troubleshooting

✓ Writing code

✓ Creating projects

✓ Improving GitHub

✓ Preparing interviews

✓ Explaining concepts

Avoid spending long periods consuming information without producing outputs.

Every session should create something.

Examples:

• Project

• Documentation

• Diagram

• README

• Script

• Pipeline

• Notes

• Interview preparation

• Debugging workflow

═══════════════════════════════════════════════════════════════════════

# PHASE 4 — SESSION REVIEW

═══════════════════════════════════════════════════════════════════════

Before ending the session,

answer:

What did I complete?

What did I build?

What did I improve?

What blocked me?

What should I stop doing?

What should I continue doing?

What permanent knowledge did I discover?

═══════════════════════════════════════════════════════════════════════

# PHASE 5 — DOCUMENT UPDATES

═══════════════════════════════════════════════════════════════════════

Always update:

✓ Weekly Execution Dashboard

Sometimes update:

✓ Career Knowledge Base

Only if timeless knowledge was discovered.

Sometimes update:

✓ Opportunity Pipeline

Only if:

• applications changed

• recruiter interactions occurred

• interviews happened

• resume changed

• LinkedIn changed

Rarely update:

✓ Career Execution Roadmap

✓ Career Operating System

Only when long-term strategy changes.

═══════════════════════════════════════════════════════════════════════

# PHASE 6 — NEXT SESSION PREPARATION

═══════════════════════════════════════════════════════════════════════

Before ending,

define:

Next Session Goal

First Task

Expected Deliverable

Expected Duration

Potential Blockers

This eliminates decision fatigue at the beginning of the next session.

Never finish a session without defining the next one.

═══════════════════════════════════════════════════════════════════════

# AI END-OF-SESSION PROMPT

═══════════════════════════════════════════════════════════════════════

At the end of every productive session, ask AI:

"Review today's work.

Summarize everything we accomplished.

Update my Weekly Execution Dashboard.

Determine whether the Career Knowledge Base should be updated.

Determine whether the Opportunity Pipeline should be updated.

Identify my biggest remaining blocker.

Recommend the single highest ROI first task for my next session.

Challenge any low-value activities.

Ensure today's work remains aligned with my Career Operating System."

# SESSION QUALITY CHECK

═══════════════════════════════════════════════════════════════════════

Before ending the session, ask:

Did I create a measurable output?

□ Yes

□ No

Did I increase my employability?

□ Yes

□ No

Did I improve my market value?

□ Yes

□ No

Did I spend time on high ROI work?

□ Yes

□ No

Did I avoid unnecessary learning?

□ Yes

□ No

Did I define the next session?

□ Yes

□ No

If any important answer is "No",

identify why before ending the session.
